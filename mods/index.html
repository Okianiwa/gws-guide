Моды сборки

В сборке больше 450 модов. Учить их по одному не нужно: у самых сложных есть свои справочники в игре, а рецепты всех — в JEI.

Как разобраться в игре

  • JEI: наведи на предмет — Отобразить рецепт покажет, как его сделать, Отобразить применения — куда он идёт. В поиске JEI @имя_мода показывает все предметы мода, например @create.
  • Ponder — у машин Create и его дополнений: в подсказке предмета написано, какую клавишу держать, и игра покажет живую сцену, как машина работает.
  • Книги модов — свои справочники у этих модов:
  • Apotheosis — книга Patchouli «Chronicle of Shadows»
  • Croptopia — книга Patchouli «Croptopia»
  • Dimensional Dungeons — книга Patchouli «Dimensional Dungeons»
  • Hexalia — книга Patchouli «Verdant Grimoire»
  • Hex Casting — книга Patchouli «Рунный блокнот»
  • Create: Occult Engineering — книга Modonomicon «Encyclopedia of Souls»
  • Occultism — книга Modonomicon «Справочник душ»
  • Simply Swords — книга Patchouli «Runic Grimoire»

Сцены Ponder есть у 29 модов: Create: Aeroworks, Create, Create: Central Kitchen, Create: Enchantment Industry, Create: Integrated Farming, Create: New Age, Create Aquatic Ambitions, Create: Connected, Create Hypertube, Create: Mechanical spawner, Create: Pattern Schematics, Create: Power Loader, Create: Radars, Create Crafts & Additions, Create Big Cannons, Create: Dragons Plus, Create Ore Excavation, Create Sifter, Create Gadgets & Gizmos, Create Aeronautics, Create Offroad, Create Simulated, Create: Escalated, Forbidden Arcanus, Create: Occult Engineering, Ponder, Create: Steam 'n' Rails 1.21.1, Create Slice & Dice, Create: Trading Floor.

  • Квестбук — Открыть квесты, по главам модов.

Свои системы сервера

  • Уровень K и навыки — общий уровень за опыт, 12 навыков и замки на предметы.
  • Навыки: что открывает уровень — пороги по каждому навыку.
  • Дерево технологий — вехи Create и AE2, без узлов не поставить ключевые машины (Открыть дерево навыков).
  • Пути Потусторонних — LOTMCraft.
  • Связки модов — что изменено в рецептах AE2 и Create.
